要求
实现 clean_scores(scores)，筛选 0~100 有效成绩，降序返回新列表，不修改原列表。

def build_summary(records, pass_mark=60):
    summary = {}
    for name, scores in records.items():
        valid_scores = [s for s in scores if 0 <= s <= 100]
        if valid_scores:
            average = sum(valid_scores) / len(valid_scores)
            status = "通过" if average >= pass_mark else "需加强"
        else:
            average = None
            status = "无有效成绩"
        summary[name] = {
            'valid_count': len(valid_scores),
            'average': average,
            'status': status
        }
    return summary

第27题：读取有效成绩（13分）
题目
实现函数 read_valid_scores(filename)。文本文件每行最多包含一个成绩，但可能出现空行、非整数文本或超出 0～100 的数。返回全部有效成绩组成的列表；忽略空行、非整数和越界成绩；文件不存在时返回空列表。要求使用 pathlib.Path 读取文件，并使用异常处理应对文件不存在和非整数文本。
参考答案
from pathlib import Path

def read_valid_scores(filename):
    path = Path(filename)
    valid_scores = []

    try:
        with path.open('r', encoding='utf-8') as f:
            for line in f:
                line = line.strip()
                if not line:
                    continue
                try:
                    score = int(line)
                except ValueError:
                    continue
                if 0 <= score <= 100:
                    valid_scores.append(score)
    except FileNotFoundError:
        return []

    return valid_scores
核心知识点
with path.open('r', encoding='utf-8') as f: 逐行读取并自动关闭文件。
① path.open('r')：以只读模式打开文件，encoding='utf-8' 指定用 UTF-8 编码解码，处理中文必需；
② with ... as f：把文件对象赋给变量 f，代码块结束后自动调用 close() 关闭文件，避免忘记关闭造成占用；
③ for line in f：直接迭代文件对象逐行读取，自动按换行符切分；
④ 内层 try 捕获 int() 的 ValueError，外层 except FileNotFoundError 处理文件不存在返回空列表。

实现函数 update_training_result(filename, name, course, score)。JSON 文件保存"姓名—课程成绩字典"。要求使用 pathlib.Path 和 json 模块。
规则：① score 不在 0～100（含边界）时直接返回 False，且不读写文件；② 正常情况下读取原有 JSON 数据，文件不存在、内容为空或 JSON 格式损坏时从空字典开始；③ 姓名不存在则新增该姓名，课程已存在则更新，否则新增；④ 将完整数据写回原文件，中文不转义并使用 2 个空格缩进；⑤ 成功后返回 True。

    "小陈": {"Python": 82},
    "小李": {"Git": 90}
}
参考答案
from pathlib import Path
import json

def update_training_result(filename, name, course, score):
    if not (0 <= score <= 100):
        return False

    path = Path(filename)

    try:
        content = path.read_text(encoding='utf-8')
        if not content.strip():
            data = {}
        else:
            data = json.loads(content)
    except (FileNotFoundError, json.JSONDecodeError):
        data = {}

    if name not in data:
        data[name] = {}
    data[name][course] = score

    path.write_text(
        json.dumps(data, ensure_ascii=False, indent=2),
        encoding='utf-8'
    )
    return True
核心知识点
先校验再读写；异常合并捕获 FileNotFoundError 与 JSONDecodeError；ensure_ascii=False + indent=2 保证中文与缩进。

def read_valid_budgets(filename):

    new_list = []

                line = line.strip()
                if line == '':          # 双等号比较
                    continue
                try:
                    budget = int(line)
                except ValueError:      # 异常类名拼写正确
                    continue
                if budget >= 0:          # 只要求 ≥0，无上限

错题 7（第28题）：更新项目培训进度
题目
实现函数 update_project_progress(filename, name, task, progress)。JSON 文件保存"姓名—任务进度字典"。要求使用 pathlib.Path 和 json 模块。
规则：
① progress 不在 0～100（含边界）时直接返回 False，且不读写文件；
② 正常情况下读取原有 JSON 数据；文件不存在、内容为空或 JSON 格式损坏时，从空字典开始；
③ 姓名不存在则新增该姓名；任务已存在则更新，否则新增；
④ 将完整数据写回原文件，中文不转义并使用 2 个空格缩进；
⑤ 成功后返回 True。
考察点核对
❌ 参数写死成字符串 Path('filename')；❌ 范围判断写反且无解 not 1>=progress>=100；❌ 读取逻辑乱，把字典当行遍历；❌ 异常类名拼成 Json.JSONDecodeError；❌ return data 过早返回挡住后续；❌ write_text 参数顺序颠倒。
✅ 正确代码（with open 读写）
from pathlib import Path
import json

def update_project_progress(filename, name, task, progress):
    path = Path(filename)

    # ① 范围不合法：不读写，直接返回 False
    if not (0 <= progress <= 100):
        return False

    # ② 读取；文件不存在或 JSON 损坏时从空字典开始
    try:
        with path.open('r', encoding='utf-8') as f:
            data = json.load(f)
    except (FileNotFoundError, json.JSONDecodeError):
        data = {}

    # ③ 姓名不存在则新增；任务已存在则更新，否则新增
    if name not in data:
        data[name] = {}
    data[name][task] = progress

    # ④ 写回：中文不转义 + 2 空格缩进（数据在前）
    with path.open('w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)

    # ⑤
    return True
核心（对应错因）
1. Path() 放变量：Path(filename) 不能加引号，否则成了真字符串"filename"。
2. 范围判断：if not (0 <= progress <= 100): return False，放在读写之前。
3. load/dump 配对：读 json.load(f)、写 json.dump(data, f, ...)；空文件与损坏 JSON 由 except json.JSONDecodeError 兜住。
4. 拼写：json.JSONDecodeError，小写 json。
5. return 只放最后：中途 return 会跳过修改与写文件。
6. 参数位置：dump 第1参是数据对象，encoding 用关键字参数。
订正小结
薄弱点
1. 循环控制：continue 只跳过剩余代码，索引自增仍需执行，不会死循环。
2. 嵌套结构访问：嵌套字典/列表要逐层取到具体键再运算/赋值。
3. JSON 读写：dumps/write_text 与 loads/read_text 要成对使用，Path 没有 write_note。
4. 判断目标：判断是否已在结果容器中，而非遍历数据本身。
5. 继承与方法副作用：class 需写父类名；返回值前要先完成修改操作。
6. 文件读取与返回值位置：try 只包可能抛异常的代码，return 放在 try 外（with 之后），不能缩进进循环内；文件不存在时 open() 已抛异常进入 except，return 永远轮不到。
7. json.load/dump 配对与参数：读 load、写 dump；path.write_text 数据在前、encoding 用关键字；异常拼成 ValueError / json.JSONDecodeError；return 只放最后。
