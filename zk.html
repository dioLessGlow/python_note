错题 1（第21题）：列表切片与排序
❌ 题目代码
original = [72, 88, 65]
copied = original[:]
copied.sort()
copied.append(90)
print(original)
print(copied)
✅ 正确输出
[72, 88, 65]
[65, 72, 88, 90]
原因分析
1. copied = original[:] 通过切片浅拷贝，copied 与 original 是两个独立列表
2. copied.sort() 原地排序只改 copied，不影响 original
3. copied.append(90) 追加 90，copied 最终为 [65, 72, 88, 90]
4. original 自始至终未被修改，保持 [72, 88, 65]
错题 2（第22题）：循环体内的缩进层级
❌ 错误代码
scores = [65, 90, 82]
passed = []
for score in scores:
    if score >= 60:
        passed.append(score)
        print(passed)   # 缩进在 if 内部
# 输出：[65] [65, 90] [65, 90, 82]（打印3次）
错误原因
print(passed) 缩进在 if 内部，每判断一个及格成绩就打印一次，共 3 次。
✅ 修正
for score in scores:
    if score >= 60:
        passed.append(score)
print(passed)   # 与 if 对齐，循环结束后执行一次
# 输出：[65, 90, 82]
错题 3（第23题）：字典嵌套修改与 get() 默认值
❌ 题目代码
profile = {'name': '陈晨', 'scores': {'Python': 82}}
profile['scores']['Python'] = 88
profile['scores']['SQL'] = 75
mentor = profile.get('mentor', '待分配')
print(profile['scores'])
print(mentor)
✅ 正确输出
{'Python': 88, 'SQL': 75}
待分配
原因分析
1. profile['scores']['Python'] = 88 键已存在 → 修改（82→88）
2. profile['scores']['SQL'] = 75 新增键值对
3. profile.get('mentor', '待分配') 键不存在 → 返回默认值，不报错
错题 4（第24题）：while 循环中的 continue 与死循环
❌ 错误代码
numbers = [1, 2, 3, 4]
index = 0
total = 0
while index < len(numbers):
    if numbers[index] % 2 == 0:
        continue       # 跳过 index += 1
    total += numbers[index]
    index += 1
错误原因
遇到偶数时 continue 跳回 while 开头，index += 1 未执行，索引永远卡在偶数位置，形成死循环。
✅ 修正
while index < len(numbers):
    if numbers[index] % 2 == 0:
        index += 1     # 先自增再 continue
        continue
    total += numbers[index]
    index += 1
# 更简洁：
while index < len(numbers):
    if numbers[index] % 2 != 0:
        total += numbers[index]
    index += 1
print(total)  # 4
错题 5（第25题）：清理成绩（函数实现）
要求
实现 clean_scores(scores)，筛选 0~100 有效成绩，降序返回新列表，不修改原列表。
错误原因
混淆 range(101) 与输入列表的遍历，return 写在循环内部导致提前结束。
✅ 正确代码
def clean_scores(scores):
    valid = [s for s in scores if 0 <= s <= 100]
    return sorted(valid, reverse=True)

scores = [86, -1, 72, 105, 90]
print(clean_scores(scores))   # [90, 86, 72]
print(scores)                 # [86, -1, 72, 105, 90] 原列表不变
核心
列表推导式过滤 + sorted() 返回新列表 + reverse=True 降序
错题 6（第26题）：记录课程成绩（函数实现）
要求
实现 record_score(profile, course, score)，成绩 0~100 时更新/新增并返回 True，否则返回 False。
错误原因
误用 input() 获取输入，if 0 >= score <= 100 语法逻辑错误，字典嵌套修改方式不正确。
✅ 正确代码
def record_score(profile, course, score):
    if 0 <= score <= 100:
        profile['scores'][course] = score
        return True
    else:
        return False

profile = {'name': '陈晨', 'scores': {'Python': 82}}
record_score(profile, 'SQL', 75)    # True，新增
record_score(profile, 'Python', 88) # True，更新
record_score(profile, 'Java', 105)  # False，不修改
核心
函数参数直接传值不用 input()；字典赋值同时实现新增和更新；返回布尔值
错题 7（第27题）：统计测试执行结果（函数实现）
要求
遍历结果列表，返回"结果名称—出现次数"字典，必须用 dict.get() 完成计数。
错误原因
未理解 dict.get() 在计数场景中的用法，代码语法混乱。
✅ 正确代码
def count_results(results):
    counts = {}
    for result in results:
        counts[result] = counts.get(result, 0) + 1
    return counts

results = ['通过', '失败', '通过', '阻塞', '失败', '通过']
print(count_results(results))
# {'通过': 3, '失败': 2, '阻塞': 1}
核心
counts.get(result, 0) + 1 是计数器经典写法，避免 if 判断分支
错题 8（第28题）：生成培训成绩汇总（综合函数实现）
要求
实现 build_summary(records, pass_mark=60)，返回新字典，不修改 records。处理有效成绩、平均值、None 及状态。
错误原因
records.items 漏括号、sum 当列表用、未筛选有效成绩、未处理无成绩、直接修改原字典、未返回正确结构。
✅ 正确代码
def build_summary(records, pass_mark=60):
    summary = {}
    for name, scores in records.items():
        valid_scores = [s for s in scores if 0 <= s <= 100]
        if valid_scores:
            average = sum(valid_scores) / len(valid_scores)
            status = "通过" if average >= pass_mark else "需加强"
        else:
            average = None
            status = "无有效成绩"
        summary[name] = {
            'valid_count': len(valid_scores),
            'average': average,
            'status': status
        }
    return summary

records = {'陈晨': [80,90,100], '李杰': [50,58], '王敏': [], '赵宇': [101,80,-1,60]}
print(build_summary(records))
期望输出
{
    '陈晨': {'valid_count': 3, 'average': 90.0, 'status': '通过'},
    '李杰': {'valid_count': 2, 'average': 54.0, 'status': '需加强'},
    '王敏': {'valid_count': 0, 'average': None, 'status': '无有效成绩'},
    '赵宇': {'valid_count': 2, 'average': 70.0, 'status': '通过'}
}
核心
.items() 需括号；列表推导式过滤；分支处理有效/无效成绩；构建新字典不修改原数据
