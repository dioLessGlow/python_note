错题 1（第21题）：列表切片与排序
❌ 题目代码
original = [72, 88, 65]
copied = original[:]
copied.sort()
copied.append(90)
print(original)
print(copied)
✅ 正确输出
[72, 88, 65]
[65, 72, 88, 90]
原因分析
1. copied = original[:] 通过切片浅拷贝，copied 与 original 是两个独立列表
2. copied.sort() 原地排序只改 copied，不影响 original
3. copied.append(90) 追加 90，copied 最终为 [65, 72, 88, 90]
4. original 自始至终未被修改，保持 [72, 88, 65]

错题 4（第24题）：while 循环中的 continue 与死循环
❌ 错误代码
numbers = [1, 2, 3, 4]
index = 0
total = 0
while index < len(numbers):
    if numbers[index] % 2 == 0:
        continue       # 跳过 index += 1
    total += numbers[index]
    index += 1
错误原因
遇到偶数时 continue 跳回 while 开头，index += 1 未执行，索引永远卡在偶数位置，形成死循环。
✅ 修正
while index < len(numbers):
    if numbers[index] % 2 == 0:
        index += 1     # 先自增再 continue
        continue
    total += numbers[index]
    index += 1
# 更简洁：
while index < len(numbers):
    if numbers[index] % 2 != 0:
        total += numbers[index]
    index += 1
print(total)  # 4
错题 5（第25题）：清理成绩（函数实现）
要求
实现 clean_scores(scores)，筛选 0~100 有效成绩，降序返回新列表，不修改原列表。
错误原因
混淆 range(101) 与输入列表的遍历，return 写在循环内部导致提前结束。
✅ 正确代码
def clean_scores(scores):
    valid = [s for s in scores if 0 <= s <= 100]
    return sorted(valid, reverse=True)

scores = [86, -1, 72, 105, 90]
print(clean_scores(scores))   # [90, 86, 72]
print(scores)                 # [86, -1, 72, 105, 90] 原列表不变
核心
列表推导式过滤 + sorted() 返回新列表 + reverse=True 降序
错题 6（第26题）：记录课程成绩（函数实现）
要求
实现 record_score(profile, course, score)，成绩 0~100 时更新/新增并返回 True，否则返回 False。
错误原因
误用 input() 获取输入，if 0 >= score <= 100 语法逻辑错误，字典嵌套修改方式不正确。
✅ 正确代码
def record_score(profile, course, score):
    if 0 <= score <= 100:
        profile['scores'][course] = score
        return True
    else:
        return False

profile = {'name': '陈晨', 'scores': {'Python': 82}}
record_score(profile, 'SQL', 75)    # True，新增
record_score(profile, 'Python', 88) # True，更新
record_score(profile, 'Java', 105)  # False，不修改
核心
函数参数直接传值不用 input()；字典赋值同时实现新增和更新；返回布尔值
错题 7（第27题）：统计测试执行结果（函数实现）
要求
遍历结果列表，返回"结果名称—出现次数"字典，必须用 dict.get() 完成计数。
错误原因
未理解 dict.get() 在计数场景中的用法，代码语法混乱。
✅ 正确代码
def count_results(results):
    counts = {}
    for result in results:
        counts[result] = counts.get(result, 0) + 1
    return counts

results = ['通过', '失败', '通过', '阻塞', '失败', '通过']
print(count_results(results))
# {'通过': 3, '失败': 2, '阻塞': 1}
核心
counts.get(result, 0) + 1 是计数器经典写法，避免 if 判断分支
错题 8（第28题）：生成培训成绩汇总（综合函数实现）
要求
实现 build_summary(records, pass_mark=60)，返回新字典，不修改 records。处理有效成绩、平均值、None 及状态。
错误原因
records.items 漏括号、sum 当列表用、未筛选有效成绩、未处理无成绩、直接修改原字典、未返回正确结构。
✅ 正确代码
def build_summary(records, pass_mark=60):
    summary = {}
    for name, scores in records.items():
        valid_scores = [s for s in scores if 0 <= s <= 100]
        if valid_scores:
            average = sum(valid_scores) / len(valid_scores)
            status = "通过" if average >= pass_mark else "需加强"
        else:
            average = None
            status = "无有效成绩"
        summary[name] = {
            'valid_count': len(valid_scores),
            'average': average,
            'status': status
        }
    return summary

records = {'陈晨': [80,90,100], '李杰': [50,58], '王敏': [], '赵宇': [101,80,-1,60]}
print(build_summary(records))
期望输出
{
    '陈晨': {'valid_count': 3, 'average': 90.0, 'status': '通过'},
    '李杰': {'valid_count': 2, 'average': 54.0, 'status': '需加强'},
    '王敏': {'valid_count': 0, 'average': None, 'status': '无有效成绩'},
    '赵宇': {'valid_count': 2, 'average': 70.0, 'status': '通过'}
}
核心
.items() 需括号；列表推导式过滤；分支处理有效/无效成绩；构建新字典不修改原数据

第25题：建立技能索引（14分）
题目
实现函数 build_skill_index(trainees)。参数 trainees 是由实习生字典组成的列表，每个字典都包含 name 和 skills。函数返回一个新字典：键为技能名，值为掌握该技能的实习生姓名列表。技能名称不固定，不得针对示例值硬编码；不得修改传入数据。
trainees = [
    {'name': '小陈', 'skills': ['Python', 'Git']},
    {'name': '小李', 'skills': ['Git', 'Linux']},
    {'name': '小王', 'skills': []},
]
# 期望返回：{'Python': ['小陈'], 'Git': ['小陈', '小李'], 'Linux': ['小李']}
参考答案
def build_skill_index(trainees):
    skill_index = {}
    for trainee in trainees:
        for skill in trainee['skills']:
            if skill not in skill_index:
                skill_index[skill] = []
            skill_index[skill].append(trainee['name'])
    return skill_index
核心知识点
嵌套遍历；字典 key 不存在时先初始化空列表再 append；构建新字典不动原数据。

class Intern(Employee):
    def __init__(self, name, direction):
        super().__init__(name)
        self.direction = direction
        self.skills = []

    def add_skill(self, skill):
        if skill not in self.skills:
            self.skills.append(skill)
            return True
        else:
            return False

第27题：读取有效成绩（13分）
题目
实现函数 read_valid_scores(filename)。文本文件每行最多包含一个成绩，但可能出现空行、非整数文本或超出 0～100 的数。返回全部有效成绩组成的列表；忽略空行、非整数和越界成绩；文件不存在时返回空列表。要求使用 pathlib.Path 读取文件，并使用异常处理应对文件不存在和非整数文本。
参考答案
from pathlib import Path

def read_valid_scores(filename):
    path = Path(filename)
    if not path.exists():
        return []

    valid_scores = []
    try:
        content = path.read_text(encoding='utf-8')
        for line in content.splitlines():
            line = line.strip()
            if line == '':
                continue
            try:
                score = int(line)
            except ValueError:
                continue
            if 0 <= score <= 100:
                valid_scores.append(score)
    except Exception:
        return []

    return valid_scores
核心知识点
Path.exists() 先判断文件；内层 try 捕获 int() 的 ValueError；外层 try 兜底文件读取异常。
第28题：更新培训成绩文件（20分）
题目
实现函数 update_training_result(filename, name, course, score)。JSON 文件保存"姓名—课程成绩字典"。要求使用 pathlib.Path 和 json 模块。
规则：① score 不在 0～100（含边界）时直接返回 False，且不读写文件；② 正常情况下读取原有 JSON 数据，文件不存在、内容为空或 JSON 格式损坏时从空字典开始；③ 姓名不存在则新增该姓名，课程已存在则更新，否则新增；④ 将完整数据写回原文件，中文不转义并使用 2 个空格缩进；⑤ 成功后返回 True。
{
    "小陈": {"Python": 82},
    "小李": {"Git": 90}
}
参考答案
from pathlib import Path
import json

def update_training_result(filename, name, course, score):
    if not (0 <= score <= 100):
        return False

    path = Path(filename)

    try:
        content = path.read_text(encoding='utf-8')
        if not content.strip():
            data = {}
        else:
            data = json.loads(content)
    except (FileNotFoundError, json.JSONDecodeError):
        data = {}

    if name not in data:
        data[name] = {}
    data[name][course] = score

    path.write_text(
        json.dumps(data, ensure_ascii=False, indent=2),
        encoding='utf-8'
    )
    return True
核心知识点
先校验再读写；异常合并捕获 FileNotFoundError 与 JSONDecodeError；ensure_ascii=False + indent=2 保证中文与缩进。
