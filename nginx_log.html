一、这个程序是做什么的

一个Nginx 访问日志分析器：解析 combined 日志格式，输出总览、状态码分布、Top IP/路径、最慢路径、小时流量柱状图、5xx 错误路径等，类比早前那版更专业、更面向真实运维。

维度本程序早前"服务器日志分析器.py"
日志格式Nginx combined（含 duration、referer、UA）NCSA 简化版
数据规模多文件批量单文件/示例
统计维度8 项（含最慢路径、小时柱状）5 项
输出文本 / JSON文本
代码结构3 个类分工（Parser/Statistics/Report）单类

二、三层类结构

类职责
NginxLogParser读行 + 正则 + 转字典 + 派生字段
Statistics从 records 计算各项指标（属性懒计算）
ReportGenerator把指标拼成可读报告

“解析 → 统计 → 输出”分层使每层可单独测试与替换。

三、combined 日志格式与正则

1. Nginx combined 格式

IP - - [21/Jul/2026:10:15:32 +0800] "GET /api/users HTTP/1.1" 200 1524 "Referer" "User-Agent" 0.045
片段说明
IP - -remote_addr / remote_user（一般 -）
[time]请求时间（含时区）
"METHOD PATH HTTP/x"请求行
status / size状态码 / 响应字节数
"Referer" "UA"来源 + 浏览器标识
duration响应耗时（秒，含小数）

2. 正则

LOG_PATTERN = re.compile(
    r'(?P<ip>\S+) \S+ \S+ \[(?P<time>[^\]]+)\] '
    r'"(?P<method>\S+) (?P<path>\S+)\s+\S+" (?P<status>\d{3}) (?P<size>\d+) '
    r'"[^"]*" "(?:[^"]*)" (?P<duration>[\d.]+)'
)
  • "[^"]*" 引用串直接跳过（不命名）。
  • (?P<duration>[\d.]+) 支持小数（响应时间 0.045）。
  • 请求行里 HTTP/1.1 用 \s+\S+ 吞掉，避免命名捕获。

四、NginxLogParser —— 解析

class NginxLogParser:
    def parse_lines(self, lines):
        records = []
        for line in lines:
            line = line.strip()
            if not line:
                continue
            m = LOG_PATTERN.match(line)
            if not m:
                continue
            d = m.groupdict()
            try:
                rec = {
                    'ip': d['ip'],
                    'time': datetime.strptime(d['time'], '%d/%b/%Y:%H:%M:%S %z'),
                    'method': d['method'],
                    'path': d['path'].split('?')[0],   # 去 query string
                    'status': int(d['status']),
                    'size': int(d['size']),
                    'duration': float(d['duration']),
                }
                rec['hour'] = rec['time'].strftime('%H')  # 派生小时字段
                records.append(rec)
            except (ValueError, KeyError):
                continue
        return records
  • 不匹配/异常都 continue 跳过，不中断整体。
  • d['path'].split('?')[0]：去掉 URL 参数，只看路径本体，避免 /api/users?id=1 与 /api/users?id=2 被当两条。
  • datetime.strptime 把字符串解析为 datetime（带时区）。
  • 派生字段 rec['hour']：按小时聚合时直接 Counter(r['hour'])，省得每次重新切字符串。

五、Statistics —— 多维统计

class Statistics:
    def __init__(self, records):
        self.records = records

    @property
    def total(self):
        return len(self.records)

    @property
    def unique_ips(self):
        return len({r['ip'] for r in self.records})   # 集合去重

    @property
    def duration_stats(self):
        if not self.records:
            return (0.0, 0.0, 0.0)
        durs = [r['duration'] for r in self.records]
        return (sum(durs) / len(durs), max(durs), min(durs))

    @property
    def status_dist(self):
        c = Counter(r['status'] for r in self.records)
        return sorted(c.items())                       # 按状态码升序

    @property
    def top_ips(self):
        return Counter(r['ip'] for r in self.records).most_common   # 返方法

    @property
    def top_paths(self):
        return Counter(r['path'] for r in self.records).most_common

    @property
    def slowest_paths(self):
        path_durs = defaultdict(list)
        for r in self.records:
            path_durs[r['path']].append(r['duration'])
        avg_durs = [(p, sum(d)/len(d), len(d)) for p, d in path_durs.items()]
        avg_durs.sort(key=lambda x: -x[1])           # 平均耗时降序
        return avg_durs

    @property
    def hourly(self):
        return Counter(r['hour'] for r in self.records)

    @property
    def err5_paths(self):
        return Counter(r['path'] for r in self.records if 500 <= r['status'] < 600)
  • 用 @property 懒计算：调用才计算，不在 __init__ 里一次性算光，调用者按需取。
  • {r['ip'] for r in self.records}：集合推导式统计唯一 IP。
  • top_ips/top_paths 返回的是 most_common 方法本身（不是结果），调用方传 N 取前 N 个（灵活）。
  • defaultdict(list) 把同一 path 的 duration 收集起来，再算每个路径的平均耗时 —— 聚合统计经典写法。
  • err5_paths 在 Counter 构造时直接过滤，避免先全量再筛。

六、ReportGenerator —— 报告生成

class ReportGenerator:
    def __init__(self, stats, top_n=10):
        self.s = stats
        self.top_n = top_n

    def generate(self):
        s = self.s
        lines = ["===== Nginx 访问日志分析报告 =====", ""]

        lines.append("[基础统计]")
        lines.append(f"  总请求数: {s.total}")
        lines.append(f"  去重 IP 数: {s.unique_ips}")
        if s.total:
            avg, mx, mn = s.duration_stats
            lines.append(f"  平均响应时间: {avg:.4f} s")
            lines.append(f"  最大响应时间: {mx:.4f} s")
            lines.append(f"  最小响应时间: {mn:.4f} s")
        lines.append("")

        lines.append("[状态码分布]")
        for code, cnt in s.status_dist:
            pct = cnt / s.total * 100
            lines.append(f"  {code}: {cnt} ({pct:5.1f}%)")
        ...
        # 5xx 错误路径 Top 5
        if not s.err5_paths:
            lines.append("  (无)")
        else:
            for path, cnt in s.err5_paths.most_common(5):
                lines.append(f"  {path:<30} {cnt} 次")

        return "\n".join(lines)
  • :5.1f：宽度 5、保留 1 位小数的浮点数对齐（如 12.5%、100.0%）。
  • f"{ip:<18}"：左对齐定宽输出，配 {cnt} 次 让对齐工整。
  • if s.total 防除零。

亮点：小时柱状图（ASCII bar）

lines.append("[按小时流量统计]")
if s.hourly:
    max_h = max(s.hourly.values())
    bar_w = 30
    for hour in sorted(s.hourly):
        cnt = s.hourly[hour]
        bar = '█' * int(cnt / max_h * bar_w) if max_h else ''
        lines.append(f"  {hour}:00 | {bar:<{bar_w}} {cnt}")
以最大时段为基准，把每小时请求数映射成 0–30 个方块字符；纯终端也能画出柱状图，运维看访问峰值很直观。

七、argparse 多文件入口

def main():
    ap = argparse.ArgumentParser(description='Nginx 访问日志分析器')
    ap.add_argument('logfile', nargs='+', help='日志文件路径')         # 支持多个文件
    ap.add_argument('--top', type=int, default=10, help='Top N 数量')
    ap.add_argument('--output', help='报告输出文件')
    ap.add_argument('--format', choices=['text', 'json'], default='text')
    args = ap.parse_args()

    all_lines = []
    for f in args.logfile:
        p = Path(f)
        if not p.is_file():
            print(f"[警告] 跳过不存在的文件: {f}")
            continue
        all_lines.extend(p.read_text(encoding='utf-8', errors='ignore').splitlines())
        #                                              ^^^^^ 跳过解码错误（坏字节）

    parser = NginxLogParser()
    records = parser.parse_lines(all_lines)
    stats = Statistics(records)
    report = ReportGenerator(stats, top_n=args.top).generate()
    print(report)
    if args.output:
        Path(args.output).write_text(report, encoding='utf-8')
        print(f"报告已写入: {args.output}")
  • nargs='+'：一次传多个日志文件，合并分析。
  • errors='ignore'：编码错误的字节静默跳过，避免单条坏数据崩溃。
  • 三层类串成管道：parse → statistics → report。

运行示例

python Nginx访问日志分析器.py access.log
python Nginx访问日志分析器.py access.log error.log --top 5
python Nginx访问日志分析器.py *.log --output report.txt

九、可扩展方向

  • 输出 JSON：把 Statistics 的属性序列化成 dict，再 json.dump。当前 --format json 字段已预留。
  • P50/P95/P99 延迟：用 statistics.quantiles 算分位数，比平均值更能反映真实体验。
  • UA / Referer 分析：补充正则命名组，加 top UA、top Referer。
  • 并发解析：大文件用 concurrent.futures 多进程切块解析。
  • 可视化：把柱状图扩展为 matplotlib 输出 PNG，喂给监控看板。
  • 实时流：用 tail -f + subprocess 持续分析新增日志。
