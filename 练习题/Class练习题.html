12. 在 BankAccount 中实现 __eq__ 方法：当两个实例的 owner 和 balance 都相等时返回 True。注意：balance 为浮点数，比较时使用容差（abs(a-b) < 0.01）而非 ==。要求：创建两个属性相同的实例和一个不同的实例，验证比较结果。

查看答案
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    @balance.setter
    def balance(self, values):
        if values < 0:
            self._balance = 0
        else:
            self._balance = values

    def __eq__(self, other):
        if not isinstance(other, BankAccount):
            return False
        return self.owner == other.owner and abs(self._balance - other._balance) < 0.01

account3 = BankAccount("张四")
account1.deposit(500)
account1.withdraw(200)

account = eval(repr(account1))
print(account3 == account1)  # False
print(account == account1)   # True（owner相同，balance相同）

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):

    @balance.setter
    def balance(self, values):

19. 定义 Money 类，属性为 amount 和 currency（货币代码，如 'CNY'、'USD'）。实现 add 方法：两个 Money 相加时，若 currency 相同则返回新的 Money（amount 相加，currency 不变）；若 currency 不同则抛出 TypeError。要求：分别测试同币种相加和异币种相加。

查看答案
class Money:
    def __init__(self, amount, currency):
        self.amount = amount
        self.currency = currency

    def add(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        if self.currency != other.currency:
            raise TypeError('货币类型不一致')
        return self.amount + other.amount, self.currency

20. 定义 TransactionHistory 继承 list。重写 append 方法：只允许追加格式为 {'type': 'deposit'/'withdraw', 'amount': 正数} 的字典；若格式不对或 amount 不是正数，则抛出 TypeError。要求：创建实例，追加合法记录和非法记录，观察差异。

class TransactionHistory(list):
    def add(self, record):
        if type(record) is not dict:
            raise TypeError('必须是字典')
        if 'type' not in record or 'amount' not in record:
            raise TypeError("字典必须包含 'type' 和 'amount' 键")
        if record['type'] not in ('deposit', 'withdraw'):
            raise TypeError("type 必须是 'deposit' 或 'withdraw'")
        if not isinstance(record['amount'], (int, float)) or record['amount'] <= 0:
            raise TypeError("amount 必须是正数")
        super().append(record)
