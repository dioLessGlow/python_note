三、判断题

1. 函数使用 return a, b 返回多个值时，实质上返回的是一个元组（ ）

2. 普通函数（不含 yield）中也可以使用 yield 来返回生成器（ ）

3. 默认参数在函数定义时求值一次，后续调用共享同一个对象（ ）

4. 递归函数如果没有基线条件（终止条件），一定会导致栈溢出错误（ ）

5. pass 语句可以在函数、类、if 语句等任何需要语法占位的地方使用（ ）

6. else 可以与 for 循环配合使用，当循环没有被 break 中断时执行（ ）

7. nonlocal 关键字可以修改嵌套函数中外部（非全局）作用域的变量（ ）

四、编程题

1. 编写函数 is_prime(n)，判断一个大于1的整数 n 是否为素数。要求时间复杂度为 O(√n)，并返回布尔值。

2. 编写递归函数 reverse_string(s)，将字符串 s 反转返回。例如 reverse_string('hello') 返回 'olleh'。要求不使用切片 [::-1] 和 reversed()。

3. 编写函数 count_elements(lst)，接收一个列表，统计每个元素出现的次数，返回字典形式如 {'a': 3, 'b': 2}。要求使用字典推导式或标准库实现。

4. 实现快速排序函数 quick_sort(arr)，对输入列表进行升序排序。要求原地排序（in-place）或不原地均可，但需注明时间复杂度。

5. 实现装饰器函数 call_counter，用于统计被装饰函数的调用次数。要求支持被装饰函数带有任意参数，并可通过 wrapper.call_count 属性获取次数。
