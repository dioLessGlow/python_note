四、编程题

1. 编写函数 is_prime(n)，判断一个大于1的整数 n 是否为素数。要求时间复杂度为 O(√n)，并返回布尔值。

查看答案
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

print(is_prime(50))  # False
print(is_prime(17))  # True

2. 编写递归函数 reverse_string(s)，将字符串 s 反转返回。例如 reverse_string('hello') 返回 'olleh'。要求不使用切片 [::-1] 和 reversed()。

查看答案
def reverse_string(s):
    if len(s) <= 1:
        return s
    return s[-1] + reverse_string(s[:-1])

print(reverse_string('hello'))  # 'olleh'

# 递归过程:
# reverse_string('hello')
# → 'o' + reverse_string('hell')
# → 'o' + 'l' + reverse_string('hel')
# → 'o' + 'l' + 'l' + reverse_string('he')
# → 'o' + 'l' + 'l' + 'e' + reverse_string('h')
# → 'o' + 'l' + 'l' + 'e' + 'h'
# → 'olleh'

3. 编写函数 count_elements(lst)，接收一个列表，统计每个元素出现的次数，返回字典形式如 {'a': 3, 'b': 2}。要求使用字典推导式或标准库实现。

查看答案
# 方法1：字典推导式 + count
def count_elements(lst):
    return {x: lst.count(x) for x in set(lst)}

# 方法2：字典 get 累加
def count_elements2(lst):
    new_dict = {}
    for i in lst:
        new_dict[i] = new_dict.get(i, 0) + 1
    return new_dict

# 方法3：标准库 collections.Counter
from collections import Counter
def count_elements3(lst):
    return dict(Counter(lst))

print(count_elements(['a','a','b']))  # {'b': 1, 'a': 2}

4. 实现快速排序函数 quick_sort(arr)，对输入列表进行升序排序。要求原地排序（in-place）或不原地均可，但需注明时间复杂度。

查看答案
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left   = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right  = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

print(quick_sort([1,5,2,3,56,4,1,3,4,1,3]))
# [1, 1, 1, 2, 3, 3, 3, 4, 4, 5, 56]

# 复杂度:
# 时间: 平均 O(n log n)，最坏 O(n²)（每次基准都选到最大/最小值）
# 空间: O(n) — 每次递归都创建新列表

5. 实现装饰器函数 call_counter，用于统计被装饰函数的调用次数。要求支持被装饰函数带有任意参数，并可通过 wrapper.call_count 属性获取次数。

查看答案
from functools import wraps

def call_counter(func):
    """
    装饰器：统计被装饰函数的调用次数
    """
    @wraps(func)  # 保留原函数的名称、文档等元信息
    def wrapper(*args, **kwargs):
        wrapper.call_count += 1  # 每次调用计数 +1
        return func(*args, **kwargs)  # 透传任意参数

    wrapper.call_count = 0  # 初始化计数器
    return wrapper

@call_counter
def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))      # Hello, Alice!
print(greet("Bob"))        # Hello, Bob!
print(greet.call_count)    # 2
