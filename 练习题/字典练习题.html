字典练习题

1. 使用 fromkeys() 创建一个字典，键为 ['a','b','c']，默认值为空列表 []。观察三个键对应的值是否为同一个列表对象（可用 id() 或 is 验证），并解释原因。写出正确的初始化方式，使每个键拥有独立的空列表。

2. 给定字典 prices = {'apple': 3.5, 'banana': None, 'cherry': 4.0}，使用 get() 获取 'banana' 的价格，若值为 None 则返回 0.0；同时使用 setdefault() 为不存在的键 'date' 设置默认值 5.0 并获取。

3. 合并两个字典 dict_a = {'x': 1, 'y': 2} 和 dict_b = {'y': 3, 'z': 4}，要求保留 dict_b 的值覆盖 dict_a。分别使用 update() 方法、| 运算符（Python 3.9+）和 {**dict_a, **dict_b} 解包三种方式实现。

4. 从字典 scores = {'Alice': 88, 'Bob': 92, 'Charlie': 85, 'David': 92} 中找出所有获得最高分的姓名，并按字母顺序排序后输出为列表。

5. 将字典 old = {1: 'a', 2: 'b', 3: 'c', 4: 'xyz'} 的键值对过滤后交换，只保留值为单个小写字母的项，生成新字典 {'a': 1, 'b': 2, 'c': 3}。

6. 计算字典 inventory = {'pen': 10, 'pencil': 0, 'eraser': 5, 'ruler': None} 中所有有效库存（值不为 None 且不为负数）的总和。

7. 检查字典 config = {'host': 'localhost', 'port': 8080} 中是否同时存在键 'host' 和 'timeout'。分别说明使用 'host' in config 和 'host' in config.keys() 的区别（从时间复杂度和返回值类型角度）。

8. 使用字典推导式生成一个字典，键为 1 到 10 的整数，值为该数的阶乘（如 {1:1, 2:2, 3:6, ...}），要求不使用 math.factorial，用推导式内部嵌套循环实现。

9. 给定字典 mixed = {'id': 42, 'name': 'Test', 'score': 98.5, 'active': True, 'tags': [1,2,3]}，提取所有值为整数类型（int）但不包括布尔类型（bool）的键。

10. 将两个等长列表 keys = ['name', 'age', 'city'] 和 values = ['Alice', 25, 'Beijing'] 组合成字典，并确保字典中所有值都是字符串类型（非字符串需通过 str() 转换）。

11. 按值对字典 grades = {'Math': 85, 'Science': 92, 'English': 78, 'History': 92} 降序排序；值相同时，按键的字母顺序升序排列。输出为 [('History', 92), ('Science', 92), ('Math', 85), ('English', 78)] 形式的列表。

12. 使用 collections.Counter 统计字符串 'abracadabra' 中每个字符出现次数，找出出现频率最高的前 3 个字符及其次数，并将结果转为普通字典。

13. 将嵌套字典 user = {'profile': {'name': 'Alice', 'contact': {'email': 'alice@example.com', 'phone': '12345'}}} 中的 'phone' 值改为 '67890'，并给 'contact' 新增 'address': 'Beijing'。要求先安全判断每层键是否存在，避免 KeyError。

14. 合并三个字典 d1 = {'a': 1}, d2 = {'b': 2}, d3 = {'a': 3, 'c': 4}，要求后面的字典覆盖前面的。分别使用 collections.ChainMap 和 {**d1, **d2, **d3} 实现，并解释两种方式在键查找和结果类型上的区别。

15. 统计字典 words = {'hello': 5, 'world': 5, 'python': 6, 'code': 4} 中值为偶数的键值对数量，并原地删除所有值小于 5 的键值对（注意遍历时直接删除的陷阱，写出正确做法）。

16. 将字典 data = {'x': 10, 'y': 20, 'z': 30} 先转换为按值升序排列的元组列表，再将其转回有序字典。说明 Python 3.7+ 中普通 dict 为何能保持插入顺序。

17. 实现一个递归函数 deep_upper(obj)，将多层嵌套字典中的所有字符串值转换为大写（如 {'a': {'b': 'hello'}} → {'a': {'b': 'HELLO'}}）；若值是列表，列表内的字典也需递归处理。

18. 给定字典 d = {'a': [1,2], 'b': [1,2]}，判断 d['a'] == d['b'] 和 d['a'] is d['b'] 的结果。随后执行 d['a'].append(3)，再次打印 d['b'] 并观察是否变化，用文字解释原因。

19. 使用 collections.defaultdict(list) 将列表 [('a', 1), ('b', 2), ('a', 3), ('c', 4), ('b', 5)] 分组为 {'a': [1, 3], 'b': [2, 5], 'c': [4]}，并说明 defaultdict 与普通 dict 在访问缺失键时的行为差异。

20. 实现一个不使用 copy 模块的 deep_copy_dict 函数，能够递归处理嵌套字典、列表和基本数据类型（int, str, bool 等）的深拷贝。用包含嵌套字典和列表的复杂结构验证：修改副本不影响原对象。
