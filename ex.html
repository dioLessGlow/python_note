一、字符串 vs 列表 —— 核心区别

         字符串 (str)                列表 (list)
         ─────────────               ──────────
 "hello"                         ['h','e','l','l','o']
 不可变（修改创建新对象）          可变（可直接修改）
 每个元素是字符                   每个元素可以是任意类型
 ' '.join(列表)  列表→字符串     字符串.split(' ')  字符串→列表
# 不可变 vs 可变
s = "hello"
s[0] = 'H'          # ❌ TypeError: 字符串不可变

lst = ['h','e','l','l','o']
lst[0] = 'H'        # ✅ 列表可直接修改

# 字符串方法返回新对象（原串不变）
s = "hello"
s.upper()           # "HELLO"（新字符串）
print(s)            # "hello"（原串不变）

二、join vs + —— 何时用哪个

+：少量拼接，直观

# ✅ 少量字符串
a = "Na"
b = a * 4 + " Batman!"   # "NaNaNaNa Batman!"

# ✅ 少数变量拼接
full = first + " " + last

# ❌ 循环中用 + 拼接大量字符串（效率低！）
result = ""
for s in big_list:          # 每次循环创建新字符串
    result += s             # O(n²) 时间复杂度

join：列表→字符串，大量拼接

# ✅ 列表转字符串（推荐）
words = ["Python", "is", "powerful"]
print(' '.join(words))        # "Python is powerful"

# ✅ 循环中收集到列表，最后 join（高效！）
parts = []
for s in big_list:
    parts.append(s)
result = ''.join(parts)        # O(n) 一次拼接

# ✅ join + 推导式（最简洁）
result = ''.join(s for s in big_list if s)

对比总结：

操作                    用 join                    用 +
──────────────────────────────────────────────────
列表→字符串              ✅ 'sep'.join(list)        ❌ 不行
少量字符串拼接            ❌ 没必要                 ✅ a + b
循环中大量拼接            ✅ join(列表)             ❌ += 效率低
数字→字符串拼接           ❌ 需先转str              ✅ str(n) + "元"
混合类型                  ❌ 需全转str              ✅ str(x) + str(y)

三、join 和 split 搭配

# 核心模式：split 切分 → 处理 → join 重组

# 1. 基础
s = "apple;banana;cherry;date"
parts = s.split(';')              # ['apple','banana','cherry','date']
result = ', '.join(parts)         # "apple, banana, cherry, date"

# 2. 过滤
s = "Temperature: -5.67°C, Humidity: 82.3%"
digits = ''.join(c for c in s if c.isdigit() or c in '.-')
# "-5.6782.3"

# 3. 替换分隔符
s = "a|b|c|d"
result = ','.join(s.split('|'))   # "a,b,c,d"

# 4. 按空格分割再重组
s = "The  quick   brown fox"
result = ' '.join(s.split())      # "The quick brown fox"（合并多余空格）

二、遍历时删除元素的正确做法

# ❌ 错误：for num in range(len(a)): a.pop(num)     → 索引错位
# ❌ 错误：for num in a: a.remove(num)              → 漏删
# ✅ 方法1：列表推导式
a = [i for i in a if condition]
# ✅ 方法2：倒序遍历删除
for i in range(len(a)-1, -1, -1):
    if condition: a.pop(i)
# ✅ 方法3：创建新列表
new_a = [i for i in a if condition]

三、列表推导式

[expression for item in iterable if condition]

# 示例
[i for i in a if i <= 10]           # 过滤
[s := s + i for i in a]            # 海象运算符累加
[len(i) for i in nested]           # 处理嵌套
[k for k, v in count.items() if v == 1]  # 字典过滤

四、列表与字典配合

# 统计次数（经典模式）
count = {}
for num in a:
    count[num] = count.get(num, 0) + 1

# 找出现最多的元素
max_key = max(count, key=count.get)

# 两个列表合成字典
d = dict(zip(keys, values))

# 分组（按首字母）
groups = {}
for item in sorted(a):
    key = item[0]
    if key not in groups:
        groups[key] = []
    groups[key].append(item)

五、浅拷贝 vs 深拷贝

b = a[:]              # 浅拷贝：外层独立，内层共享
c = copy.copy(a)      # 同上
d = copy.deepcopy(a)  # 深拷贝：完全独立

# 浅拷贝 = 换外壳，里面装的东西还是同一批
# 深拷贝 = 连里面装的东西也全部重新复制了一份
