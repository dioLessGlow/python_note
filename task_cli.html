一、这个程序是做什么的

一个命令行任务管理器：用 JSON 文件持久化任务数据，支持添加、列出、（标记）完成、删除、查过期、统计、搜索，交互全部走命令行。

命令作用
add添加任务（标题 + 优先级 + 截止日期 + 标签）
list列出任务，可按状态/标签过滤、按字段排序
done把某任务标记为完成
remove删除某任务
overdue显示已过期且未完成的任务
stats任务总数/完成数/优先级分布统计
search按标题关键词搜索

三、读写 tasks.json

def load_tasks():
    if not TASKS_FILE.exists():
        return {"tasks": [], "next_id": 1}          # 首次运行：空数据
    try:
        data = json.loads(TASKS_FILE.read_text(encoding='utf-8'))
    except json.JSONDecodeError:
        return {"tasks": [], "next_id": 1}          # 文件损坏：兜底
    if "next_id" not in data:                       # 旧数据补字段
        data["next_id"] = max((t.get("id", 0) for t in data.get("tasks", [])),
                              default=0) + 1
    return data

def save_tasks(data):
    TASKS_FILE.write_text(json.dumps(data, ensure_ascii=False, indent=2),
                          encoding='utf-8')
  • 读写统一 ensure_ascii=False, indent=2：中文不转义、方便阅读。
  • 兜底：文件不存在、JSON 损坏都返回空结构，程序不崩。
  • 老数据若缺 next_id，用最大 id + 1 补上。

四、add —— 添加任务（带校验）

def cmd_add(args, data):
    title = args.title
    priority = args.priority
    due = args.due
    tags = [t.strip() for t in (args.tags or "").split(",") if t.strip()]

    if not (1 <= priority <= 5):
        print("[错误] 优先级必须在 1-5 之间")
        return 1
    try:
        datetime.strptime(due, "%Y-%m-%d")
    except ValueError:
        print("[错误] 截止日期格式应为 YYYY-MM-DD")
        return 1

    task = {
        "id": data["next_id"], "title": title, "priority": priority,
        "due_date": due, "tags": tags, "status": "pending",
        "created_at": datetime.now().isoformat(timespec='seconds'),
    }
    data["tasks"].append(task)
    data["next_id"] += 1
    save_tasks(data)
    print(f"✅ 任务已添加 (ID: {task['id']})")
校验用 argparse type=int 保证 priority 是整数，用 datetime.strptime(..., "%Y-%m-%d") 验证日期合法（非法抛 ValueError → 捕获返回错误码 1）。isoformat(timespec='seconds') 生成带秒的时间戳字符串。

tags 解析：把逗号分隔字符串拆开并去掉空白，过滤空标签（一段列表推导式）。

五、list —— 列出与过滤排序

def cmd_list(args, data):
    tasks = list(data["tasks"])
    if args.status:
        tasks = [t for t in tasks if t["status"] == args.status]  # 状态过滤
    if args.tag:
        tasks = [t for t in tasks if args.tag in t.get("tags", [])]  # 标签过滤

    if args.sort:
        if args.sort == "priority":
            tasks.sort(key=lambda t: -t["priority"])   # 高优先级在前
        elif args.sort == "due_date":
            tasks.sort(key=lambda t: t["due_date"])    # 按截止日期
        elif args.sort == "created_at":
            tasks.sort(key=lambda t: t["created_at"])
    ...
    print(f"{'ID':<4} | {'标题':<12} | {'优先级':<5} | {'截止日期':<12} | {'状态':<8} | 标签")
    print("-" * 70)
    for t in tasks:
        mark = "✅" if t["status"] == "done" else "⏳"
        tags = ", ".join(t.get("tags", []))
        print(f"{t['id']:<4} | {t['title']:<12} | ... | {mark:<8} | {tags}")
  • 过滤用列表推导式产生新列表，不污染原数据。
  • 排序用 sort(key=...)：priority 取负（1 最高排前）、due_date/created_at 字符串可比大小。
  • f"{x:<4}" 左对齐定宽，配合 | 拼成对齐表格。

六、done / remove —— 修改与删除

def cmd_done(args, data):            # 完成任务
    tid = args.task_id
    for t in data["tasks"]:
        if t["id"] == tid:
            t["status"] = "done"
            save_tasks(data)
            print(f"✅ 任务 #{tid} \"{t['title']}\" 已标记为完成")
            return 0
    print(f"[错误] 找不到任务 #{tid}")
    return 1

def cmd_remove(args, data):          # 删除任务
    tid = args.task_id
    for i, t in enumerate(data["tasks"]):
        if t["id"] == tid:
            data["tasks"].pop(i)
            save_tasks(data)
            print(f"🗑️  任务 #{tid} 已删除")
            return 0
    print(f"[错误] 找不到任务 #{tid}")
  • 遍历找 id，命中就改并 save_tasks；enumerate 拿索引配合 pop(i) 删除。
  • 找不到时打印错误并 return 1（非零退出码表示失败）。
  • 修改直接作用于 data（同一字典引用），无需返回新值。

八、argparse 子命令分发

def main():
    ap = argparse.ArgumentParser(description='命令行任务管理器')
    sub = ap.add_subparsers(dest='cmd')               # 注册"子命令"

    p_add = sub.add_parser('add', help='添加任务')
    p_add.add_argument('title')
    p_add.add_argument('--priority', type=int, default=3, help='优先级 1-5')
    p_add.add_argument('--due', required=True)
    p_add.add_argument('--tags', default='')
    # list / done / remove / overdue / stats / search —— 同 motik，逐个注册参数
    args = ap.parse_args()

    if not args.cmd:                                  # 没给命令 → 打印帮助
        print("用法: ... 可用命令: ...")
        return 0

    data = load_tasks()
    handlers = {
        'add': cmd_add, 'list': cmd_list, 'done': cmd_done,
        'remove': cmd_remove, 'overdue': cmd_overdue,
        'stats': cmd_stats, 'search': cmd_search,
    }
    return handlers[args.cmd](args, data)             # 字典分发：命令 → 函数映射

if __name__ == "__main__":
    raise SystemExit(main())
  • add_subparsers(dest='cmd')：每个子命令独立定义参数，互不干扰。
  • choices=VALID_STATUS 让 argparse 直接拒绝非法取值，少写校验。
  • 用 dict[命令] = 处理函数 做“命令分发”，比一长串 if/elif 清晰，加命令只需加一个键值对。
  • 没有命令时打印完整用法清单。

十、可扩展方向

  • JSON 错误处理增强：损坏时备份原文件再重建，避免数据丢失。
  • 编辑命令 edit：类似 done/remove，加一个能改标题/优先级/日期的命令。
  • 批量完成：支持多个 id（nargs='+'）。
  • 周期任务 recurrence：到期后自动生成下一个日程。
  • 配置化存储：用 --data 参数或环境变量指定数据文件位置。
  • 模糊搜索 / 排序多级：按优先级再按日期二级排序。
