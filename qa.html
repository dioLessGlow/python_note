函数参数关于函数参数，以下调用方式正确的是？def func(a, b=10, *args, c, d=20, **kwargs): pass
答案是 A) func(1, 2, 3, 4, c=5, d=6, e=7)
参数拆解：
a → 位置参数（必须）
b=10 → 默认参数
*args → 接收多余的位置参数 (3, 4)
c → 仅关键字参数（必须关键字传参）
d=20 → 仅关键字参数（默认20）
**kwargs → 多余关键字参数 {'e': 7}

生成器以下关于生成器函数的说法，错误的是？
A) 包含 yield 的函数调用时返回生成器对象
B) 生成器可以使用 next() 逐个获取值
C) 生成器函数执行到 return 后会继续从头执行
D) 生成器表达式使用圆括号 () 定义
答案是 C) 生成器函数执行到 return 后会继续从头执行 ❌
生成器遇到 return 就彻底结束，抛 StopIteration，不会从头执行。
def my_gen():
    yield 1
    yield 2
    return 3          # 结束生成器
g = my_gen()
print(next(g))   # 1
print(next(g))   # 2
print(next(g))   # StopIteration（结束）

要重新遍历必须重新调用函数创建新生成器。
生成器什么是生成器
生成器是一种特殊的迭代器，用 yield 实现"一边循环一边计算"，省内存。
两种创建方式：
1. 生成器函数（含 yield）
def my_gen():
    yield 1
    yield 2
    yield 3
g = my_gen()
print(next(g))  # 1

2. 生成器表达式（圆括号）
gen = (x*2 for x in range(1000000))  # 几乎不占内存

对比普通函数：yield 暂停保存状态，next() 唤醒继续。适合大文件、无限序列等场景。
生成器def my_gen(): yield 1 yield 2 yield 3 return 4 yield 3 yield 3 g = my_gen() print(next(g)) print(next(g)) print(next(g)) print(next(g))
执行过程：
next(g) → yield 1 → 返回 1，暂停
next(g) → yield 2 → 返回 2，暂停
next(g) → yield 3 → 返回 3，暂停
next(g) → return 4 → 抛 StopIteration，生成器报废
return 后面的 yield 3, yield 3 永远不会执行。
获取 return 的值：
try:
    print(next(g))
except StopIteration as e:
    print(f"return 的值: {e.value}")   # 4
nonlocalx = 10 def outer(): x = 20 def inner(): nonlocal x x = 30 inner() print(x) outer() print(x) 输出？
输出：
30
10
nonlocal x 让 inner 修改外层 outer 的局部变量（20→30），不影响全局的 x（仍是10）。
对比：
- 不写：创建 inner 自己的局部变量
- global x：修改全局变量
- nonlocal x：修改外层函数的变量
嵌套函数nonlocal，inner()是什么
inner() 是嵌套在 outer() 里的内部函数，只能在 outer() 内部调用。
nonlocal 是 Python 3 关键字，用于在嵌套函数中修改外层函数的变量。
def outer():
    x = 20
    def inner():
        nonlocal x    # 改 outer 的 x，不是创建自己的
        x = 30
    inner()
    print(x)          # 30

三种情况对比：不写→创建局部变量；global→改全局；nonlocal→改外层函数的变量。

生成器普通函数（不含 yield）中也可以使用 yield 来返回生成器（ ）
错。一旦写了 yield，函数就变成生成器函数，不再是普通函数。
函数体中出现 yield → 生成器函数，调用返回生成器对象。
普通函数不含 yield，用 return 返回值。
生成器怎么区别普通函数，生成器函数
def normal():       # 普通函数
    return 1
def gen():          # 生成器函数
    yield 1

核心区别：
- 普通函数：return 返回值，一次性执行完
- 生成器函数：yield 暂停，返回生成器对象，用 next() 唤醒
验证：
import inspect
print(inspect.isgeneratorfunction(normal))  # False
print(inspect.isgeneratorfunction(gen))     # True
综合默认参数在函数定义时求值一次，后续调用共享同一个对象（ ）
