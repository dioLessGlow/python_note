一、这个程序是做什么的

一个中文交互式命令行任务管理器：数据显示为对齐表格，支持任务的增删改查、多方式排序筛选、截止前 1 小时自动/手动提醒（发到 WPS 群）。特点是中文终端对齐与Webhook 通知。

菜单功能
1添加新任务
2查看所有任务（按紧急程度排序）
3修改任务（内容/截止/状态/优先级）
4删除任务（带确认）
5查看今日任务
6按状态排序查看
7按截止日期排序（升/降序）
8手动检查并发送截止提醒
0保存并退出

三、显示函数：中文对齐与数据读写

1. 让中英文占位一致的对齐工具

def display_width(s):                 # 中文占2，英文占1
    width = 0
    for ch in str(s):
        if '\u4e00' <= ch <= '\u9fff' or '\u3000' <= ch <= '\u303f' or '\uff00' <= ch <= '\uffef':
            width += 2
        else:
            width += 1
    return width

def pad_to_width(s, target_width):
    s = str(s)
    current = display_width(s)
    if current > target_width:            # 超长 → 截断并加 "..."
        result, w = "", 0
        for ch in s:
            cw = 2 if  else 1
            if w + cw > target_width - 3:
                result += "..."; break
            result += ch; w += cw
        return result + " " * (target_width - display_width(result))
    return s + " " * (target_width - current)   # 不足 → 补齐空格
⚠️ 关键点：终端里英文/数字占 1 列、中文占 2 列。若只用 f"{x:<22}"，含中文时列会歪。此工具按显示宽度计算并补齐，保证中文列表对齐。

2. 数据读写

def load_data():
    try:
        with open(DATA_FILE, 'r', encoding='utf-8') as f:
            return json.load(f)
    except (json.JSONDecodeError, FileNotFoundError):
        print("⚠️ 数据文件损坏或不存在，已创建新文件")
        data = {"tasks": [], "next_id": 1}
        save_data(data); return data

def save_data(data):
    with open(DATA_FILE, 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)

def generate_task_id(next_id):
    return f"task_{next_id:03d}"     # task_001, task_002 ...

def parse_datetime(dt_str):
    try:
        return datetime.strptime(dt_str.strip(), "%Y-%m-%d %H:%M:%S")
    except ValueError:
        return None                  # 格式错返回 None，调用方兜底

:03d 零填充三位数字生成 ID；文件读取用 with+json，读写都规定 utf-8。

七、截止提醒（WPS Webhook）

def send_webhook_message(content):
    if not HAS_REQUESTS:
        print("⚠️ 未安装 requests 库，pip install requests"); return False
    headers = {"Content-Type": "application/json"}
    data = {"msgtype": "text", "text": {"content": content}}
    try:
        response = requests.post(WEBHOOK_URL, headers=headers,
                                 data=json.dumps(data, ensure_ascii=False).encode('utf-8'),
                                 timeout=10)
        result = response.json()
        if response.status_code == 200 and (
            result.get("errcode") in (0, "0") or result.get("success") is True
            or result.get("result") == "ok"):
            return True
        print(f"⚠️ Webhook 返回：{result}"); return False
    except Exception as e:
        print(f"❌ 发送失败：{e}"); return False

def check_reminders():      # 检查截止前1小时的任务
    now = datetime.now()
    one_hour_later = now + timedelta(hours=1)
    for task in data["tasks"]:
        if task["status"] not in ["未开始", "进行中"]: continue
        deadline = parse_datetime(task["deadline"])
        if not deadline: continue
        if now <= deadline <= one_hour_later:      # 恰好落在未来1小时内

九、数据模型与字段对照

{
  "id": "task_001", "create_time": "2025-07-24 10:00:00",
  "deadline": "2025-07-24 18:00:00", "task": "完成基础数据类型学习",
  "status": "进行中", "priority": 1
}
字段类型约束
id字符串唯一，task_{NNN:03d}
create_time字符串格式 YYYY-MM-DD HH:MM:SS
deadline字符串格式 YYYY-MM-DD HH:MM:SS
task字符串任务描述
status字符串未开始/进行中/已完成/推迟
priority整数1=最高，越大越低

数据文件 {"tasks": [...], "next_id": N}，自增 next_id 用于生成新 ID。

十、与「任务管理器 CLI」对比及扩展

维度Task Manager CLITo-Do List（本篇）
交互方式子命令（add/list/done…）交互菜单（1-8 数字选择）
状态pending / done未开始/进行中/已完成/推迟
对齐西文 f-string 左对齐中文按显示宽度对齐（中文各 2 列）
提醒无WPS Webhook 群消息，截止前 1 小时
逾期处理无启动自动标记「推迟」+ 标红
颜色无ANSI 红色高亮，Windows 适配

可扩展方向

  • 日期相对提醒：支持今天/明天/本周分组。
  • 进度百分比：任务加 progress 字段，展示进度条。
  • 配置化 Webhook：key 从环境变量或配置文件读取，避免硬编码。
  • 标签/备注：按数据模型预留空间添加 tags、note 字段。
  • 自动刷新：后台线程循环检查提醒，而非仅启动/手动。
