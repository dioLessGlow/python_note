一、这个程序是做什么的

一个自动化运维小工具：读取 Web 服务器（如 Nginx/Apache）的访问日志，自动算出关键指标，发现异常时发出告警。

功能模块具体作用
日志解析用正则从日志中提取 IP、时间、方法、URL、状态码、响应大小、响应时间
基础统计总/有效/无效请求数，平均响应时间、最大响应时间、平均响应大小
状态码分析统计 200、404、500 等状态码次数和占比
Top N 排行访问最频繁的 IP、请求最多的 URL（Top 3）
智能告警5xx 错误率过高？响应太慢？某 IP 恶意刷接口？
报告输出格式化成分清晰的中文文本报告

意义：生产日志每天几十万行，人工翻找不现实。它把“读日志→算指标→找异常→出报告”整条运维流程自动化，是常见的面试/练习编程题，也是实用的工具原型。

二、从模块开始（文件顶部）

import re                       # 正则表达式引擎
from collections import Counter # 自动计数器
from pathlib import Path        # 现代化文件路径工具
  • re：标准库自带。本程序用它 re.compile(...) 预编译正则，再用 .match() 逐行匹配。像一台“文字安检仪”。
  • Counter：自动计数的字典。给列表即可统计每个元素出现次数，most_common(n) 直接按次数降序取前 n 个，不需要手写循环计数。

四、正则表达式 LOG_PATTERN

想系统学正则：推荐先背熟基础元字符，多用 regex101.com 实时测试。

1. 最常用的 6 个函数

函数作用返回值
re.match(pattern, string)从字符串开头匹配Match 对象或 None
re.search(pattern, string)搜索第一个匹配Match 对象或 None
re.findall(pattern, string)找到所有匹配列表
re.sub(pattern, repl, string)用 repl 替换所有匹配新字符串
re.compile(pattern)预编译重复使用Pattern 对象

2. 基础元字符

.   任意单个字符（除换行）    \d 数字       \D 非数字
\w  单词字符（字母数字下划线）\W 非单词字符  \s 空白
\S  非空白                   ^ 开头        $ 结尾
*   0次或多次   + 1次或多次   ? 0次或1次    {n,m} n到m次
[]  字符集（[^abc]表"非"）    | 或           () 分组
.*  贪婪匹配                 .*? 非贪婪匹配

量词后加 ? 变成非贪婪（*?、+?）：尽可能少匹配。

3. 命名分组 (?P<名字>...)

pattern = r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})"
m = re.search(pattern, "2026-08-06")
print(m.group("year"))    # 2026
print(m.groupdict())      # {'year':'2026','month':'08','day':'06'} ← 本程序精髓

groupdict() 直接把匹配结果转成字典，方便后续处理。

4. 拆解本程序的 LOG_PATTERN

LOG_PATTERN = re.compile(
    r'(?P<ip>\S+) (?P<ts>\S+) '
    r'"(?P<method>\S+) (?P<url>\S+) (?P<inner_status>\d+)" '
    r'(?P<status>\d+) (?P<size>\d+) (?P<duration>\d+)'
)

对应示例日志：

192.168.1.10 2026-07-23T10:05:32 "GET /api/users 200" 200 1524 45
正则片段含义匹配结果
(?P<ip>\S+)命名分组 ip，非空白字符192.168.1.10
(?P<ts>\S+)命名分组 ts（时间戳）2026-07-23T10:05:32
" 字面量双引号匹配双引号"
(?P<method>\S+)命名分组 methodGET
(?P<url>\S+)命名分组 url/api/users
(?P<inner_status>\d+)命名分组 inner_status200
(?P<status>\d+)命名分组 status200
(?P<size>\d+)命名分组 size1524
(?P<duration>\d+)命名分组 duration45
  • \S 匹配非空白字符，IP/时间戳/URL 均无空格，用 \S+ 最合适。
  • r'...' 原始字符串，确保 \S、\d 不被 Python 先转义（否则要写成 \\S）。
  • 分多行 r'...' 字符串会自动拼接，仅为换行美观。

五、LogAnalyzer 类与 __init__

为什么要用类：日志分析器有状态（记录解析结果）有行为（加载、分析、告警），用类把数据和操作打包，复用方便。
class LogAnalyzer:
    def __init__(self, source=None):
        self.source = source        # 日志来源（文件路径或 None）
        self.records = []           # 解析出的有效记录（字典列表）
        self.skip_count = 0         # 跳过的错误行数
        self.total_lines = 0        # 文件总行数

self 代表当前实例。类像模具，self 是用模具造出的具体实例。此时 records 还是空盒子。

六、load —— 读取并解析日志

def load(self):
    lines = self._read_lines()     # 1. 拿到所有行
    self.total_lines = len(lines)  # 2. 总行数
    for line in lines:
        line = line.strip()            # 去首尾空白
        if not line: continue          # 跳过空行
        m = LOG_PATTERN.match(line)    # 4. 正则匹配
        if not m:                      # 格式错误
            self.skip_count += 1
            continue
        d = m.groupdict()              # 5. 提取命名分组
        try:
            rec = {
                'ip': d['ip'],
                'timestamp': d['ts'],
                'method': d['method'],
                'url': d['url'],
                'status': int(d['status']),
                'size': int(d['size']),
                'duration_ms': int(d['duration']),
            }
            self.records.append(rec)   # 6. 存入 records
        except (ValueError, KeyError):
            self.skip_count += 1       # 转换失败也跳过
            continue

数据流转：原始日志行 → 正则匹配 LOG_PATTERN.match → groupdict() 字典 → 数字字段 int() → append 进 records。

注意 groupdict() 取出的值都是字符串，所以 status/size/duration 要 int() 转类型。try/except 保证某行转整数失败或缺键时优雅跳过，不崩溃。

七、_read_lines —— 数据源

def _read_lines(self):
    if self.source is None:              # 情况A：未传路径
        return SAMPLE_LOG.splitlines()   # 用内置示例
    p = Path(self.source)
    if p.is_file():                      # 情况B：文件存在
        return p.read_text(encoding='utf-8').splitlines()
    return SAMPLE_LOG.splitlines()       # 情况C：文件不存在 → 回退示例
场景结果
LogAnalyzer() 不传参用内置 SAMPLE_LOG
LogAnalyzer("access.log") 文件存在读取真实文件
LogAnalyzer("不存在") 回退到内置示例

前导下划线 _read_lines：Python 约定表示“私有方法”，类内部用，外部别直接调。splitlines() 按换行切成列表，如 "a\nb".splitlines() → ['a','b']。

8.1 基础统计

lines.append("===== 服务器日志分析报告 =====")
lines.append("")
lines.append("[基础统计]")
lines.append(f"总行数: {self.total_lines} | 有效请求: {valid} | 跳过行数: {self.skip_count}")

    avg_dur = sum(r['duration_ms'] for r in recs) / valid

    avg_size = sum(r['size'] for r in recs) / valid
    lines.append(f"平均响应时间: {avg_dur:.2f} ms | 最大响应时间: {max_dur} ms")
    lines.append(f"平均响应大小: {avg_size:.2f} bytes")
else:
    lines.append("平均响应时间: 0.00 ms | 最大响应时间: 0 ms")
    lines.append("平均响应大小: 0.00 bytes")

  • if valid: 判空避免除以 0（ZeroDivisionError）。
  • f"{x:.2f}" 保留两位小数。

九、_check_alerts —— 告警引擎

def _check_alerts(self, rules, top_n):
    if not recs:
        return []
    alerts = []
    total = len(recs)

    # 规则1：5xx 错误率
    err_rate = rules.get('error_rate_threshold')
    if err_rate is not None:
        err5 = sum(1 for r in recs if 500 <= r['status'] < 600)
        rate = err5 / total * 100
        if rate > err_rate:
            alerts.append(f"5xx 错误率 {rate:.2f}% 超过阈值 {err_rate}%")

    # 规则2：平均响应时间
    slow = rules.get('slow_request_threshold_ms')
    if slow is not None:
        avg = sum(r['duration_ms'] for r in recs) / total
        if avg > slow:
            alerts.append(f"平均响应时间 {avg:.2f}ms 超过阈值 {slow}ms")

    # 规则3：单 IP 请求上限
    ip_max = rules.get('single_ip_max_requests')
    if ip_max is not None:
        ip_cnt = Counter(r['ip'] for r in recs)
        for ip, cnt in ip_cnt.most_common(top_n):
            if cnt >= ip_max:
                alerts.append(f"IP {ip} 请求 {cnt} 次，达到上限 {ip_max}")
    return alerts
  • rules.get(...) 取阈值，is not None 防止未配置时误触。
  • sum(1 for ... if 500<=status<600) 满足条件记 1，最后求和即 5xx 数量（条件计数技巧）。
  • 注意区别：错误率用 >（超过才告警），单 IP 用 >=（达到上限即告警）。

十、main 与 if __name__

def main():
    import sys
    src = sys.argv[1] if len(sys.argv) > 1 else None
    rules = {
        "error_rate_threshold": 20.0,
        "slow_request_threshold_ms": 1000,
        "single_ip_max_requests": 3,
    }
    analyzer = LogAnalyzer(src)
    analyzer.load()
    print(analyzer.analyze(alert_rules=rules, top_n=3))

if __name__ == "__main__":
    main()
  • sys.argv[0] 是脚本名，sys.argv[1] 是第一个命令行参数（日志路径），没有则 src=None。
  • 三步走：创建对象 → load() 解析 → analyze() 生成并打印。
  • if __name__ == "__main__":：直接运行该文件时 __name__=='__main__' 才执行 main；被 import 时不会。方便复用 LogAnalyzer，公共逻辑不自动触发。
  • 运行方式：
    python 服务器日志分析与告警系统.py               # 用内置示例
python 服务器日志分析与告警系统.py access.log  # 用真实文件

十一、完整数据流转

access.log / SAMPLE_LOG
      │
      ▼
  _read_lines()  按行读取，返回列表
      │
      ▼
     load()      逐行正则解析 LOG_PATTERN.match
      │          成功 → 字典 → records[]
      │          失败 → skip_count++
      ▼
   analyze()     基于 records 统计：基础统计 / 状态码 / TopN
      │
      ▼
 _check_alerts() 按规则检测异常
      │
      ▼
   文本报告字符串 → return / print

十二、关键设计思想

设计原因
类封装把“读-解析-分析-输出”封装在一起，复用方便
load 与分析分离解析只做一次，分析可多次（换规则、换 top_n）
正则命名分组groupdict() 直接变字典，代码简洁
Counter 统计不手写循环计数，代码短且高效
列表拼接报告比字符串 += 高效，逻辑清晰
边界处理空文件、全错、无告警都有兜底，不崩

十四、番外：NCSA 格式分析器（服务器日志分析器.py）

上面用的是自定义格式（IP+时间戳+带引号请求）。这一版是更标准的 NCSA / Common Log 格式（Apache 默认），并演示 datetime 时间解析与 emoji 报告。

1. 日志格式与正则

IP - - [21/Jul/2026:10:15:32 +0800] "GET /api/users HTTP/1.1" 200 1524

LOG_PATTERN = re.compile(
    r'(?P<ip>\S+) \S+ \S+ \[(?P<time>[^\]]+)\] '
    r'"(?P<method>\S+) (?P<path>\S+) \S+" (?P<status>\d{3}) (?P<size>\d+)'
)
片段含义匹配
(?P<ip>\S+)IP192.168.1.10
\S+ \S+remote logname、auth user（通常为 -）- -
\[(?P<time>[^\]]+)\]中括号内的时间戳[21/Jul/2026:10:15:32 +0800]
"...HTTP/1.1"请求行带协议版本（\S+ 吞掉）"GET /api/users HTTP/1.1"
(?P<status>\d{3})三位状态码200
(?P<size>\d+)响应字节数1524

与自定义版不同：时间带方括号（\[[^\]]+\]），请求行以 \S+ 吞掉 HTTP 版本，状态码限定三位 \d{3}。

2. 时间解析 parse_log_line

LOG_PATTERN = re.compile(...)  # 模块级编译一次，复用

def parse_log_line(line):
    m = LOG_PATTERN.match(line.strip())
    if not m:
        return None                              # 匹配失败 → None
    d = m.groupdict()
    d['status'] = int(d['status'])               # 字符串转 int
    d['size'] = int(d['size'])
    try:
        d['time_obj'] = datetime.strptime(d['time'], '%d/%b/%Y:%H:%M:%S %z')
    except ValueError:
        return None                              # 时间格式错也跳过
    return d
  • datetime.strptime(str, 格式) 把字符串解析成 datetime 对象。
  • 格式码：%d日、%b月缩写(Jul)、%Y年、%H:%M:%S时分秒、%z时区(+0800)。
  • 解析失败抛 ValueError，捕获后返回 None，纳入容错。

3. 类与报告

class LogAnalyzer:
    def __init__(self, source=None):
        self.entries = []      # 解析出的记录
        self.source = source
    def load(self):            # 逐行解析进 self.entries
    def _read_lines(self):     # 同前面：文件或内置示例
    def report(self):          # 生成报告
        total = len(entries)
        total_bytes = sum(e['size'] for e in entries)
        times = [e['time_obj'] for e in entries]
        time_min, time_max = min(times), max(times)      # datetime 可直接比大小

        status_cnt  = Counter(e['status'] for e in entries)
        method_cnt  = Counter(e['method'] for e in entries)
        ip_cnt      = Counter(e['ip'] for e in entries)
        path_cnt    = Counter(e['path'] for e in entries)
        anomalies   = [e for e in entries if e['status'] >= 400]

新增亮点：

  • min/max(times)：datetime 对象支持比较，直接求整段日志的时间范围。
  • {total_bytes:,}：千分位格式化输出大数。
  • sorted(method_cnt.items(), key=lambda x: -x[1])：按次数降序（负号反转）。
  • anomalies = [e if e['status'] >= 400]：筛出 4xx/5xx 异常请求。
  • 用了 %Y-%m-%d %H:%M:%S / %H:%M:%S 二次格式化时间，f"{ip:<15}" 左对齐对齐列。
