一、这个工具是做什么的

一个 JSON 数据差异对比工具：递归比较两份 JSON，找出哪些字段被新增 / 删除 / 修改，并统计差异类型，输出一份人类可读的报告。

差异类型含义示例
added 新增b 里有、a 没有的键/元素新增 email
deleted 删除a 里有、b 没有的键/元素删除 phone
modified 修改两边都有但值不同age 25 → 26
type_changed 类型变更值的类型都变了int → str

二、项目结构（三个角色）

文件职责
differ.py核心算法：Differ 类递归对比，产出差异记录
formatter.py把差异记录格式化串联成文本报告 + 统计
main.py命令行入口：解析参数、加载 JSON、调用上面两者

“核心算法 / 展示 / 入口”分离——算法改了不影响展示，是良好分层。

三、类型判断 _type_name

def _type_name(value):
    if isinstance(value, bool):
        return 'bool'            # Python 中 bool 是 int 的子类！
    if isinstance(value, int):
        return 'int'
    if isinstance(value, float):
        return 'float'
    if isinstance(value, str):
        return 'str'
    if isinstance(value, list):
        return 'list'
    if isinstance(value, dict):
        return 'dict'
    if value is None:
        return 'null'            # JSON 标准里叫 null
    return type(value).__name__  # 兜底：其他类型
⚠️ 为什么先判断 bool？因为 Python 里 True == 1、isinstance(True, int) 为真。必须把 bool 放在 int 前面，否则 True 会被误判成 int。

四、Differ —— 递归差异对比

class Differ:
    def __init__(self, ignore_paths=None, tolerance=None):
        self.ignore_paths = set(ignore_paths or [])  # 短路求值：None → []
        self.tolerance = tolerance
        self.stats = Counter()                        # 统计各类差异次数

    def diff(self, a, b, path=''):
        return self._diff(a, b, path)

    def _should_ignore(self, path):
        return path in self.ignore_paths   # 该路径是否要忽略

    def _diff(self, a, b, path):
        if self._should_ignore(path):
            return []                              # 1. 忽略指定路径

        if type(a) != type(b):                     # 2. 类型不同 → 类型变更
            self.stats['modified'] += 1
            return [self._change_record(path, a, b, type_changed=True)]

        if isinstance(a, dict):                    # 3. 字典 → 递归字典
            return self._diff_dict(a, b, path)
        if isinstance(a, list):                    # 4. 列表 → 递归列表
            return self._diff_list(a, b, path)
        if a != b:                                 # 5. 标量值不同
            return [self._change_record(path, a, b, type_changed=False)]
        return []                                  # 6. 相同 → 无差异
  • 递归终止：类型不同或标量不等就返回记录，否则继续往下钻。
  • type 判断顺序：第 2 步用 type(a) != type(b)（精确类型），第 3、4 步用 isinstance（允许子类）。
  • self.stats['modified'] += 1 用 Counter，不存在时自动从 0 开始，不用先初始化。

差异记录的样子

{'type': 'deleted', 'path': 'address.city', 'old': 'Beijing'}
{'type': 'added', 'path': 'email', 'new': 'alice@example.com'}
{'type': 'modified', 'path': 'age', 'old': 25, 'new': '26',
 'old_type': 'int', 'new_type': 'str', 'type_changed': True}

五、字典对比 _diff_dict

def _diff_dict(self, a, b, path):
    results = []
    for key in a:                              # 第一轮：扫 a，找删除
        sub = f"{path}.{key}" if path else str(key)
        if key not in b:
            self.stats['deleted'] += 1
            results.append({'type': 'deleted', 'path': sub, 'old': a[key]})
        else:
            results.extend(self._diff(a[key], b[key], sub))   # 同键递归
    for key in b:                              # 第二轮：扫 b，找新增
        if key not in a:
            sub = f"{path}.{key}" if path else str(key)
            self.stats['added'] += 1
            results.append({'type': 'added', 'path': sub, 'new': b[key]})
    return results
两轮循环目的：第一轮发现 a 中 b 没有的键（删除），第二轮发现 b 中 a 没有的键（新增），且都不越过对方遍历范围，避免漏项。路径用 . 连接，如 address.city。

六、列表对比 _diff_list

def _diff_list(self, a, b, path):
    results = []
    max_len = max(len(a), len(b))
    for i in range(max_len):
        sub = f"{path}[{i}]"                   # 按下标对齐，路径用 [i]
        if i >= len(a):
            self.stats['added'] += 1
            results.append({'type': 'added', 'path': sub, 'new': b[i]})
        elif i >= len(b):
            self.stats['deleted'] += 1
            results.append({'type': 'deleted', 'path': sub, 'old': a[i]})
        else:
            results.extend(self._diff(a[i], b[i], sub))    # 同下标递归
    return results

说明：列表按下标逐位比较，超出对方长度的部分记为新增/删除。这是“位置敏感”的朴素算法，适合定长或顺序稳定的列表。

七、Formatter —— 人类可读报告

class Formatter:
    @staticmethod
    def format(diffs):
        lines = ["=== JSON Diff Report ===", ""]
        for d in diffs:
            if d['type'] == 'added':
                lines.append(f"[新增] {d['path']}: {Formatter._repr(d['new'])}")
            elif d['type'] == 'deleted':
                lines.append(f"[删除] {d['path']}: {Formatter._repr(d['old'])}")
            elif d['type'] == 'modified':
                if d.get('type_changed'):
                    lines.append(f"[修改] {d['path']}: {Formatter._repr(d['old'])} → "
                                 f"{Formatter._repr(d['new'])} "
                                 f"(类型变更: {d['old_type']} → {d['new_type']})")
                else:
                    lines.append(f"[修改] {d['path']}: {Formatter._repr(d['old'])} → "
                                 f"{Formatter._repr(d['new'])}")
        lines.append("")
        lines.append("--- 统计 ---")
        stats = Counter(d['type'] for d in diffs)
        type_changed = sum(1 for d in diffs if d.get('type_changed'))
        lines.append(f"新增: {stats['added']}  |  删除: {stats['deleted']}  |  "
                     f"修改: {stats['modified']}  |  类型变更: {type_changed}")
        return "\n".join(lines)

    @staticmethod
    def _repr(v):                       # 保持可读性的值格式化
        if isinstance(v, str):
            return f'"{v}"'              # 字符串加引号
        if v is None:
            return 'null'
        if isinstance(v, (dict, list)):
            return json.dumps(v, ensure_ascii=False)   # 压缩成单行
        return str(v)
  • @staticmethod 静态方法：不依赖实例，直接 Formatter.format(...) 调用。
  • Counter(d['type'] for d in diffs) 一句统计各类型数量。
  • _repr 让字符串带引号、None 显 null、字典/列表压缩成单行，方便阅读。

八、main 命令行入口

def load_input(path_or_json):          # 参数既可能是文件也可能是 JSON 字符串
    p = Path(path_or_json)
    if p.is_file():
        text = p.read_text(encoding='utf-8-sig')   # 兼容 BOM 头的文件
        return json.loads(text)
    return json.loads(path_or_json)

def main():
    ap = argparse.ArgumentParser(description='JSON 数据差异对比工具')
    ap.add_argument('a', help='第一个 JSON 文件或 JSON 字符串')
    ap.add_argument('b', help='第二个 JSON 文件或 JSON 字符串')
    ap.add_argument('-o', '--output', help='输出到文件')
    ap.add_argument('--ignore', nargs='*', default=[], help='忽略的路径')
    ap.add_argument('--tolerance', type=float, default=None, help='浮点数精度容差')
    args = ap.parse_args()

    differ = Differ(ignore_paths=args.ignore, tolerance=args.tolerance)
    diffs = differ.diff(a, b)
    report = Formatter.format(diffs)
    print(report)
    if args.output:
        Path(args.output).write_text(report, encoding='utf-8')
        print(f"\n报告已写入: {args.output}")
    return 0

if __name__ == "__main__":
    raise SystemExit(main())
  • utf-8-sig：能处理 Windows 记事本保存的带 BOM 头的 UTF-8 文件。
  • --ignore：忽略指定路径（用 nargs='*' 接收多个）。
  • --tolerance：浮点容差，预留参数。
  • raise SystemExit(main())：把返回值当进程退出码。

九、实测演示

对比 test_data\a.json 与 test_data\b.json：

a.json:
{
  "name": "Alice", "age": 25,
  "address": { "city": "Beijing", "zip": "100000" },
  "hobbies": ["reading", "swimming"]
}

b.json:
{
  "name": "Alice", "age": "26",
  "address": { "city": "Shanghai", "zip": "200000", "street": "Nanjing Road" },
  "hobbies": ["reading", "cycling", "running"],
  "email": "alice@example.com"
}
=== JSON Diff Report ===

[修改] age: 25 → "26" (类型变更: int → str)
[修改] address.city: "Beijing" → "Shanghai"
[修改] address.zip: "100000" → "200000"
[修改] hobbies[1]: "swimming" → "cycling"
[新增] address.street: "Nanjing Road"
[新增] hobbies[2]: "running"
[新增] email: "alice@example.com"

--- 统计 ---
新增: 3  |  删除: 0  |  修改: 3  |  类型变更: 1

说明：age 的 25（int）变成 "26"（str）触发 类型变更；字典新增 street、列表多出 running、整份多出 email。

十、可扩展方向

  • 实现 tolerance：当前 --tolerance 已接收但未参与比较。可在 _diff 对标量比较前，对数值做 abs(a-b) <= tolerance 判定。
  • 旁路匹配：列表支持按内嵌对象主键（如 id）对齐，而非按下标，更适合无序 JSON 数组。
  • 感应已知修改的判定：现在修改与类型变更分开统计；可增加权重汇总，输出更智慧的总结。
  • 多格式输出：报告除文本外支持 JSON / CSV / HTML，便于接入看板。
  • 豁免路径通配：--ignore 支持 users[*].password 这类通配路径。
